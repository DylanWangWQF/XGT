# XGT  
**XGT: Fast and Secure Decision Tree Training and Inference on GPUs**

This repository contains the source code for the paper published in *IEEE Transactions on Dependable and Secure Computing* ([XGT](https://www.computer.org/csdl/journal/tq/5555/01/11122265/2965ViLYNnq)).

XGT is built on top of the GPU MPC platform [Piranha](https://github.com/ucbrise/piranha).  
Setup and installation instructions can be found in the Piranha repository.  
Configuration parameters and file paths are defined in: `files/samples/localhost_config.json`.

To run tests on a single machine with multiple GPUs, please refer to [these instructions](https://github.com/ucbrise/piranha/issues/1).
